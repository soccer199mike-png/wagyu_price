# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
 GitHubなどのオンラインサーバー上のリポジトリと、個人PCなどの専用リポジトリ

## プッシュとマージの違いは何でしょうか？
 プッシュは自分のPCから、ネット上のリポジトリへの変更
 マージはローカルのブランチの変更を今開いているブランチに合流させる

## コミットとプッシュの違い
 コミットは変更なようをローカル保存
 プッシュはその保存をサーバー上に更新

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
 後から変更理由が一目でわかりやすいように書くのが最適

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
 前者は個人だけで完了できて、後者は複数人の確認の上完了できる
